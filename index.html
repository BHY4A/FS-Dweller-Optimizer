Where to find your save:

• Windows (Steam) — %USERPROFILE%\Documents\My Games\Fallout Shelter\
• Windows (Bethesda) — %LOCALAPPDATA%Low\BethesdaSoftworks\Fallout Shelter\
• iOS — via an iTunes/Finder file-share backup of the app
Quit the game fully before copying the file out, and keep your own backup of the original. Files ending in .sav.bkp are the game's own recovery backups — leave those alone.
On Android the folder looks empty — how do I get the file out?
Since Android 11 apps cannot browse into another app's folder under Android/data, and on Android 13–14 the built-in file manager is blocked as well. The save is still there; you just need a way in.

From a PC — with USB debugging on:
adb pull /sdcard/Android/data/com.bethsoft.falloutshelter/files/Vault1.sav

Or on the phone alone, using Shizuku — it grants apps ADB-level access without root:
1. Install Shizuku and start its service, either through wireless debugging or a one-off ADB command. It needs restarting after every reboot.
2. Use a file manager that supports it — FV File Manager, ZArchiver or MiXplorer — and switch Shizuku on in its settings.
3. Copy Vault1.sav to Downloads and work on that copy, then put the optimised file back under the same name.

A rooted phone can skip Shizuku and use any root-capable file manager.

STEP 1 — ROOM ASSIGNMENTS not run

Every dweller has a talent. The trick is not finding it — it's not wasting it.
Each dweller is matched to the room whose SPECIAL stat they serve best, solved as one optimal assignment problem rather than greedy guesswork. Training rooms compete for the same people using growth headroom instead of current output, so your weakest dwellers go and improve instead of idling in a job they're bad at.
0.00 = squeeze every drop of production out of today  |  0.60 = aggressively raise the next generation
Run assignment does Step 1 only — it works out who should be in which room, and stops there so you can review it.
Run all steps does the same and then continues straight through Steps 2–5 in order: room assignments → outfits → weapons → pets → breeding suggestions. The order matters, because outfits and pets are fitted to whatever the room plan decided. Nothing is written to disk by either button — every step just fills in its section below, and your save is only changed when you press Download optimized save at the bottom.

STEP 2 — OUTFITS not run

A lab coat on a reactor tech is a wasted lab coat. Dress for the job you've been assigned.
Every worn and stored outfit is pooled and redistributed so each bonus lands on the dweller whose assigned room actually needs that stat. Run Step 1 first — outfits are fitted to the room plan.

STEP 3 — WEAPONS not run

Radroaches don't care who's holding the Gauss rifle. Deathclaws do.
The best guns go to the best fighters — provably optimal pairing, since total firepower is the sum of (combat rating × weapon damage).

Combat rating = Strength × Agility × (1 + 0.05 × (Perception + Luck)) × (max HP / 100). Strength pushes damage toward the top of the weapon's range, Agility sets attack rate, Perception slows the crit reticle, Luck sets how often crits appear, and max HP — which the game derives from level and trained Endurance — decides how long they live to keep swinging.

STEP 4 — PETS not run

Morale is a resource too. So is a dog that finds twice the junk.
Pet bonuses are stored in the save itself, so the only question is who benefits most. Training boosts go to someone actually in a training room with stat headroom left, healing to the worst wounded, damage to your best fighter, wasteland finds to whoever is actually out there. A pet with nobody useful to carry it stays in storage rather than being wasted.

STEP 5 — BREEDING PAIRS not run

The Vault's greatest long-term investment has always been its next generation.
A child inherits its highest base stat from one parent at roughly even odds — outfit bonuses don't count — and a higher combined parent SPECIAL total raises the chance of a Rare or Legendary child. Charisma speeds up conception.

Advisory only: this is never written to the save, because pairing in-game also requires physically putting the two dwellers in Living Quarters together.

EXPORT

Keep a copy of your original save. Only rooms with a meaningful SPECIAL stat are rewritten. Living Quarters, Storage, the Vault Door, elevators and the Overseer's Office are left exactly as they were, and dwellers away on quests are never touched. Whichever steps you've run are the ones that get applied.
Everything runs locally in your browser — the save is decrypted, edited and re-encrypted on your machine and is never transmitted anywhere.

Weapon damage and outfit SPECIAL bonuses are the real values from the game's own data files; two independent extractions were cross-checked and agreed on every overlapping entry. Room-to-stat mapping for training rooms is confirmed the same way. Crafting workshops deliberately use an average-of-all-SPECIAL approximation, because crafting speed depends on which specific recipe is being worked — something the save file doesn't record. The Barbershop counts Charisma (it speeds up appearance changes) but is not a training room: it doesn't raise the stat itself.
